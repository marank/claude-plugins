# Code of Conduct

<Project> follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful and constructive, assume good intent, and keep discussions about
the work. Harassment and personal attacks are not tolerated.

Report unacceptable behaviour privately to the maintainers through
**Security → Report a vulnerability** on GitHub (it reaches only them) or by email to
<CONDUCT_EMAIL>. Reports are handled confidentially.
